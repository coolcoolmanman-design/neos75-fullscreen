## Mac 桌面端：整屏主题

玻璃桌面程序新增 **整屏主题** 页签（KSS 风格 480×360 整屏构图）。

### 怎么用
1. 下载下方 Actions 产物：`Neos75-macOS-arm64.zip` / `Neos75-macOS-x64.zip`
2. 解压打开 `Neos75-Fullscreen.app`
3. 切到「整屏主题」→ 选主题 / auto → 预览 → 推送或同步

源码运行：`python3 desktop/app.py`

### 本版相对 mac-studio-v0.1.0
- 桌面 UI 整屏主题页（不再只有 CLI）
- macOS 正在播放（Music / Spotify）
- 打包清单纳入 studio_bridge + themes

说明：docs/MAC_STUDIO.md
CLI 仍可用：`python3 mac/studio.py`
